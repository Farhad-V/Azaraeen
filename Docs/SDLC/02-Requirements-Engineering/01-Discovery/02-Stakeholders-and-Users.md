## Stakeholders and users

| Stakeholder or user | Role and needs |
|---|---|
| Samira | Portfolio owner and primary project contributor; controls content, publication, access and the private application archive. |
| Farhad | Collaborates with Samira on project delivery. Detailed work allocation remains flexible. |
| Public visitors | View published public introductory content and can request access by email. |
| Employers and recruiters using application access | Use credentials associated with a company and position to view protected published content and the resume sent for that application. Contact details are optional; credential use does not verify individual identity. |
| Approved direct requesters | Receive access following owner approval and view the owner-designated main resume. |

Visitor categories describe usage contexts, not separate per-content permission tiers. One valid visitor authentication unlocks all published protected content, with application-specific resume selection. The application archive is owner-only.

Project decision-making is recorded in [Project Planning](../../01-Project-Planning/01-Project-Definition/01-Project-Plan.md). User needs inform the [functional requirements](../02-Requirement-Specification/01-Functional-Requirements.md).
