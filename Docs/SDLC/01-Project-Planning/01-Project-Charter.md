# Project Charter

Azaraeen is Samira's bilingual portfolio and private job-application archive. Samira decides scope, publication and access policy. Farhad collaborates on delivery.

## MVP

Deliver a public English/German introduction, protected case studies and certificates, access grants and email requests, owner administration and a searchable private archive with exact submitted resume versions.

The MVP excludes multiple templates, advanced page builders, inbox imports, detailed visitor tracking and a separate follow-up dashboard. Success is demonstrated through the acceptance matrix and release checks.
