## 3. Scope and deliverables

### In scope for MVP

- Public introduction and resume summary.
- Content administration and configurable public/private visibility.
- Protected case studies, documents and full resume access.
- Application-specific access, validity management and basic visit counts.
- Email-based access requests, receipt acknowledgement and owner-approved automatic access delivery.
- Private, manually maintained application archive with documents, history and search.
- Application-specific resume versions and a main resume for direct access requests.
- English/German content, translation approval, preview and publication controls.

### Out of scope for MVP

Multiple templates, advanced page builders, page/download analytics, automatic application-inbox import and a separate upcoming-task dashboard.

### Deliverables

Planning; requirements and acceptance criteria; system analysis; system design and hosting assessment; subsequent UX/UI design; implementation; validation evidence; deployment and owner guidance. These are expected outputs, not completed work.

## 4. High-level requirements

Support public discovery, approved access to private content, owner administration, application tracking and bilingual publication. Protection must cover original files as well as pages. Archived submissions must survive later content edits.

Detailed feature decisions are maintained in the Requirements baseline.
