## Design specifications and handoff

## Purpose

Index the design information needed to implement and review the interface. Original screen, component and prototype specifications remain in UX/UI Design. Handoff is a collaboration activity between design and implementation, not a separate SDLC phase or the end of design participation.

## Source material

Link to the approved screen/prototype version, reusable components and interaction states. Add responsive behavior, assets, accessibility guidance and English/German content/fallback rules where relevant. Reference acceptance criteria in Requirements rather than copying them.

The primary screen and component specifications stay in their original design documents or Figma sources; this document indexes the implementation-ready versions and records any additional delivery notes.

## Collaboration

Implementation questions and their resolutions are recorded in Implementation and Design Collaboration. Update the original design source when an agreed resolution changes the intended interface. Verification of the implemented result belongs to the Testing workstream.
