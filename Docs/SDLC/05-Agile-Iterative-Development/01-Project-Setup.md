# Project Setup

Application code belongs under `Application/Frontend` and `Application/Backend`. These directories currently contain placeholders. The runtime, database and package tooling still need a stack decision.

After selection, record installation, environment setup, migrations, seed fixtures, startup and test commands. Use synthetic application records and private attachments locally. Keep credentials and owner data outside Git. Verify a clean checkout can complete the documented workflow.
