# Azaraeen

Azaraeen is Samira's English/German portfolio and private job-application archive. The MVP includes public and protected portfolio content, visitor access grants, owner publishing, and history with the exact resume sent for each application. The repository currently documents the work; the application directories are ready for implementation.
